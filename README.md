# Хатинка хвостиків

Мобільний застосунок, який допомагає знайти тваринку з притулку й подарувати їй дім.
UI/UX case study: дизайн у Figma → робочий застосунок на Expo / React Native.

Натисни на картинку або посилання — відео (1:51) завантажиться, і його можна переглянути на компʼютері чи телефоні.

## Що вміє застосунок

- **Онбординг і вхід** — три слайди про ідею, вхід через Apple з підтвердженням Face ID.
- **Головна** — тваринки, що шукають дім, тваринки поруч, притулки, способи допомогти.
- **Вибір міста** — міста України; притулки на сторінці «Притулки» змінюються залежно від міста, з переходом на реальну карту.
- **Каталог тварин** — колода карток зі свайпами (вправо — в обране з анімацією сердечка) або список, де лайк ставиться подвійним тапом.
- **Фільтри** — категорії «Коти», «Собаки», «Інші» та панель знизу зі статтю, віком і здоровʼям.
- **Підбір тваринки** — обираєш риси характеру й одразу бачиш, скільки тваринок підходить.
- **Картка тваринки** — фото, характер, здоровʼя та історія.
- **Анкета на усиновлення** — кілька кроків із прогресом і екран успішної заявки.
- **Профіль** — обране, мої заявки, донати, чати, сповіщення.
- **Пошук** — кнопка в нижньому меню плавно перетікає в рядок пошуку.

## Технології

- [Expo](https://expo.dev) SDK 58, React Native, TypeScript
- Expo Router — навігація файлами в `src/app`
- Reanimated і Gesture Handler — анімації та свайпи
- expo-image, Expo Google Fonts (Nunito Sans, Inter)

## Як запустити

```bash
npm install
npx expo start
```

Відскануй QR-код з термінала камерою телефона — застосунок відкриється в [Expo Go](https://expo.dev/go).
Веб-версія: `npx expo start --web`.

## Структура

```
src/app/         екрани (кожен файл — окрема сторінка)
src/components/  спільні компоненти: картки, панелі, меню
src/data/        дані тваринок, притулків, міст і обраного
assets/images/   фото тваринок, ілюстрації, логотипи притулків
media/           демо-відео й прев'ю
```
